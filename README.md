# IoT-Based Smart Agriculture Monitoring System

Monitor soil moisture and reservoir water level with an Arduino UNO and ESP8266. The ESP8266 sends readings to a dashboard using MQTT. A servo can demonstrate a small valve.

## Project status

Repository setup. Hardware integration and dashboard work are next.

## Planned features

- Read soil moisture from the FC-28 sensor
- Measure reservoir water level with the HC-SR04
- Send readings through MQTT using the ESP8266
- Display readings on an online dashboard
- Demonstrate a small valve with an SG90 servo
